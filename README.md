# AnimeCreate Studio

Одностраничная HTML-студия для создания аниме-сцен, персонажей, промптов, раскадровки и простого таймлайна. Работает без сборки: достаточно открыть `index.html` или поднять маленький локальный сервер.

## Как запустить на компьютере

Самый надёжный вариант — локальный сервер из папки проекта:

```bash
cd /workspace/animecreate
python3 -m http.server 4173
```

После запуска открой в браузере:

```text
http://127.0.0.1:4173/index.html
```

Если Python недоступен, можно просто открыть файл `index.html` двойным кликом, но импорт JSON и некоторые браузерные функции стабильнее работают через `http://`.

## Как открыть на телефоне в той же Wi‑Fi сети

1. Подключи компьютер и телефон к одной Wi‑Fi сети.
2. На компьютере запусти сервер:

   ```bash
   cd /workspace/animecreate
   python3 -m http.server 4173 --bind 0.0.0.0
   ```

3. Узнай IP-адрес компьютера в локальной сети:

   ```bash
   hostname -I
   ```

   Обычно нужен первый адрес вида `192.168.x.x` или `10.x.x.x`.

4. На телефоне открой браузер и введи адрес:

   ```text
   http://IP_КОМПЬЮТЕРА:4173/index.html
   ```

   Например:

   ```text
   http://192.168.1.25:4173/index.html
   ```

5. Если страница не открывается, проверь, что телефон и компьютер точно в одной сети, а firewall/антивирус не блокирует порт `4173`.

## Как запустить прямо на телефоне без компьютера

Есть два простых способа:

- **Через любой файловый менеджер:** скопируй на телефон файлы `index.html`, `styles.css`, `app.js` в одну папку и открой `index.html` в браузере.
- **Через мобильный локальный сервер:** установи приложение для статического сервера, выбери папку с этими тремя файлами и открой адрес, который покажет приложение.

Важно: все три файла должны лежать рядом в одной папке, потому что `index.html` подключает `styles.css` и `app.js` относительными путями.

## Как выложить, чтобы открывалось ссылкой

Чтобы открыть студию на любом телефоне по ссылке, загрузи файлы на любой статический хостинг:

- GitHub Pages;
- Netlify;
- Vercel;
- любой обычный веб-хостинг.

Нужно загрузить минимум эти файлы:

```text
index.html
styles.css
app.js
```

После публикации открой полученную ссылку на телефоне.

## Что умеет страница

- редактирование названия, жанра, синопсиса, героя, эмоций, внешности, цветов, локации и камеры;
- живое превью персонажа и сцены;
- генерация промпта для изображения/видео;
- добавление, дублирование и удаление кадров таймлайна;
- настройка FPS и запуск визуальной анимации;
- экспорт и импорт проекта в JSON;
- адаптивная мобильная версия.

## Если сейчас нет компьютера

Я добавил отдельный файл `animecreate-mobile.html` — это вся студия в одном HTML-файле, внутри уже есть стили и JavaScript.

Как открыть только с телефона:

1. Скачай или получи файл `animecreate-mobile.html` на телефон.
2. Открой его через браузер или файловый менеджер.
3. Если браузер не открывает файл напрямую, загрузи `animecreate-mobile.html` на любой бесплатный статический хостинг/файловый хостинг, который отдаёт HTML как страницу, и открой ссылку.

Этот вариант не требует рядом `styles.css` и `app.js`, потому что всё уже встроено в один файл.
